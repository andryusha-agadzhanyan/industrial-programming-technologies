## 4. Модель данных и функции

Задача содержит четыре поля: положительный целочисленный `id`, строковое `title`, логическое `completed` и приоритет `low`, `medium` или `high`. Новая задача создаётся с `completed: false`. Название очищается от пробелов по краям и должно иметь длину от 1 до 100 символов.

`data.js` хранит общий набор и данные варианта. `task-service.js` содержит функции работы с задачами и не выполняет вывод. `main.js` последовательно вызывает функции и показывает результаты.

При успехе функции создания и изменения возвращают объект с `ok: true`, а при ожидаемой ошибке — `ok: false` и текст ошибки.

**Почему id не равен индексу:** индекс — это позиция элемента в массиве, а `id` — постоянный идентификатор записи. После удаления элемента индексы могут измениться, а `id` остальных задач остаются прежними.

**Почему `getTaskStats` возвращает число, а не строку с процентом:** функция выполняет расчёт, а форматирование для вывода делается отдельно в `main.js` через `toFixed(1)`.

**Какие объекты копируются при изменении задачи:** создаётся новый массив и новый объект изменяемой задачи. Остальные неизменённые объекты можно использовать повторно.
